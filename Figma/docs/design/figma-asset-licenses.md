# Figma 设计资源许可

本文件定义项目采用设计资源时的登记要求。以下 Lucide、Inter、Noto 的许可正文保留为参考，不表示当前项目已采用这些资源；不限定必须使用这些图标或字体，也不声明新项目已完成许可核验。

## 实际资源登记

每项实际采用的图标、字体、图片、组件或其他资源应记录：名称、精确来源与版本、许可标识和原文位置、用途、是否修改、嵌入/分发方式、必要声明及核查证据。登记到 figma-state.json 的 assets 列表；未采用时保持空列表，不填虚构的通过结论。

在设计工具中可用不等于可随软件打包；按实际使用与分发方式核查。保留实际采用资源的版权和许可声明，不将仓库 LICENSE 当成第三方资产许可。新增或替换资源时更新登记。

## 保留的许可参考

下列来源与 blob SHA 是既有参考记录，本次仅保留正文；使用前核对所选资源的真实版本与许可。
